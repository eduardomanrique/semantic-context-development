# Expense Reimbursement Application

## Purpose

Build a small but real expense reimbursement system with a frontend, backend, and persistence layer.

The system exists so employees can record business expenses, submit them for review, managers can decide whether submitted claims should move forward, and finance users can complete reimbursement after approval.

## Primary actors

- Employee
- Manager
- Finance user

## High-level workflow intent

1. An employee creates an expense claim.
2. The employee submits the claim for review.
3. A manager reviews the submitted claim and decides whether it should move forward.
4. Finance completes reimbursement only after managerial approval.

## Scope guidance

- Keep the application small.
- Structure it as a real application with frontend, backend, and persistence.
- Maintain Semantic Context as the source of truth for intended behavior.
